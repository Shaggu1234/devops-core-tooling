

\# Contributing Guidelines



Thank you for contributing to DevOps Core Tooling.



\## Development Workflow



1\. Clone the repository.

2\. Create a feature branch.

3\. Implement the required changes.

4\. Run Flake8 and Pytest.

5\. Commit your changes with a descriptive message.

6\. Push the feature branch.

7\. Create a Pull Request against main.

8\. Address reviewer feedback.



\## Branch Naming



Use descriptive branch names:



\- feature/feature-name

\- bugfix/issue-name

\- documentation/update-name



\## Commit Message Convention



Use clear commit messages:



\- feat: add new functionality

\- fix: resolve an issue

\- docs: update documentation

\- test: add or update tests

\- ci: update CI workflow



\## Code Quality



All contributions should:

\- Follow Python coding standards.

\- Pass Flake8 validation.

\- Pass relevant Pytest unit tests.

\- Include documentation when necessary.



\## Pull Request Guidelines



Every Pull Request should include:

\- Summary of changes.

\- Reason for the change.

\- Testing details.

\- Related issue reference, if applicable.



\## Code of Conduct



All contributors are expected to follow the

Contributor Covenant Code of Conduct:



https://www.contributor-covenant.org/version/2/1/code\_of\_conduct/
